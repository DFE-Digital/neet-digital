Accessibility statement

This accessibility statement applies to the Get help if you’re finding college or sixth form hard prototype.

This prototype is run by the Department for Education. We want as many people as possible to be able to use this prototype. For example, that means you should be able to:

  • change colours, contrast levels and fonts using browser or device settings
  • zoom in up to 400% without the text spilling off the screen
  • navigate most of the prototype using a keyboard or speech recognition software
  • listen to most of the prototype using a screen reader (including the most recent versions of JAWS, NVDA and VoiceOver)

We’ve also made the prototype text as simple as possible to understand.

AbilityNet has advice on making your device easier to use if you have a disability.

How accessible this prototype is

We know some parts of this website are not fully accessible:

  • No nav landmark. The page does not explicitly identify the primary navigation content using ARIA role="nav" or the HTML element.
  • Links do not have accessible names.
  • The <textarea> form control does not have an associated <label> element, and Table headers not correctly marking up.
  • The ‘Department for Education’ logo does not have visible keyboard focus.
  • The links within the footer of the service do not respond to text resizing.

Feedback and contact information

If you find any problems not listed on this page or think we’re not meeting accessibility requirements, contact: NationalCareersService.PMO@education.gov.uk

Enforcement procedure

The Equality and Human Rights Commission (EHRC) is responsible for enforcing the Public Sector Bodies (Websites and Mobile Applications) (No. 2) Accessibility Regulations 2018 (the ‘accessibility regulations’). If you’re not happy with how we respond to your complaint, contact the Equality Advisory and Support Service (EASS) .

Technical information about this prototype’s accessibility

The Department for Education is committed to making its prototypes accessible, in accordance with the Public Sector Bodies (Websites and Mobile Applications) (No. 2) Accessibility Regulations 2018.

Compliance status

The website has been tested against the Web Content Accessibility Guidelines (WCAG) 2.2 AA standard.

This website is partially compliant with the Web Content Accessibility Guidelines version 2.2 AA standard, due to the non-compliances listed below.

Non-accessible content

The content listed below is non-accessible for the following reasons.

Non-compliance with the accessibility regulations

  • No nav landmark. The page does not explicitly identify the primary navigation content using ARIA role="nav" or the HTML element. WCAG 2.2 Success Criterion: 2.4.1 Bypass Blocks. We plan to make sure there is a nav landmark.
  • Links do not have accessible names. WCAG 2.2 Success Criterion 2.4.4: Link Purpose (In Context). We plan to make sure all links have accessible names.
  • The <textarea> form control does not have an associated <label> element, and table headers not correctly marking up. WCAG 2.2 Success Criterion 1.3.1: Info and Relationships. We plan to make sure the form control does not have the associated label element, and we plan to mark up table headings.
  • The ‘Department for Education’ logo does not have visible keyboard focus. WCAG 2.2 Success Criterion 2.4.7 - Focus Visible – Level AA.
  • The links within the footer of the service do not respond to text resizing. WCAG 2.2 Success Criterion 1.4.4 - Resize text – Level AA.
  • The guide cards uses the incorrect focus styling. WCAG 2.2 Success Criterion 1.4.3 - Contrast (Minimum) - Level AA.

We plan to fix these accessibility issues by September 2026 to make sure we're compliant.

Preparation of this accessibility statement
